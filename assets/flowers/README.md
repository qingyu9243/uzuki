# Flower atlas

`stems.png` was generated with the built-in imagegen tool for the Uzuki bouquet studio. It is illustrative artwork, not verified product photography. Twelve transparent cells in a 4 × 3 grid, consumed with CSS background positions. Sample prices are defined in `bouquet.js`.

Generation prompt: A precise 4 column by 3 row uniform transparent sprite atlas of separate complete upright handmade flower stems. Soft natural studio lighting, realistic crochet cotton yarn and fuzzy chenille textures, warm pastel colors. Row 1: pink tulip, blush rose, pale pink peony, ivory lily. Row 2: golden sunflower, lavender hydrangea, white daisies, baby's breath. Row 3: lavender sprig, eucalyptus, olive leaf, fern. Every cell equal dimensions; no grid lines, text, labels, pots, wraps, hands or background shadows.
